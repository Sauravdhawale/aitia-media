# aitia-media

Aitia Media's responsive landing page, featuring a cinematic video hero, services, website projects, creative work, FAQs, and company contact links.

## Preview locally

Open `index.html` in a browser. No installation or build step is required. Fonts, background video, and external project links require an internet connection.

## Files

- `index.html` — the complete website with inline styles, JavaScript, and embedded logo.
- `.openai/hosting.json` — Sites hosting configuration.
