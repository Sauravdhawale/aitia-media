# Aitia Media

A responsive, multipage agency website with Aitia's original logo, red brand accents, self-hosted Bricolage Grotesque and Geist Mono fonts, light/dark/system themes, and a framed editorial layout.

## Run

Requires Node.js 18 or newer. No dependencies to install.

```sh
npm run build
npm run check
npm start
```

Open http://127.0.0.1:4173. Deploy the generated `dist/` directory to a static host. Root HTML files also support direct opening and GitHub Pages hosting.

## Pages

Home, About, Services, Work, Contact, Privacy & Site Information, B2B Lead Generation, Demand Generation, Account Based Marketing, Content Syndication, Digital Marketing, Web Development, and Brand Identity. The build also supplies a 404 page.

## Edit

- `scripts/build.cjs`: service data, page copy, shared header/footer, illustrations, and placeholder images. Run the build after editing.
- `assets/theme.css`: theme variables, spacing, type, layouts, and responsive styles for 375px and larger.
- `assets/site.js`: themes, mobile navigation, and contact brief preparation.
- `assets/aitia-logo.png`: original Aitia logo recovered from repository history.
- `assets/*.svg`: sized image placeholders generated by the build. To replace one, update its reference in the template and remove that placeholder's generation from the build script.

The contact form works locally: it prepares a brief for the visitor to copy and send through the existing Aitia Media LinkedIn page. It does not submit or store enquiries. Connect a real form endpoint before changing this behaviour or claiming delivery. No invented performance statistics or testimonials are included.

Fonts are open-source font assets (Bricolage Grotesque and Geist Mono), licensed under the SIL Open Font License. The design uses the supplied reference's typography, neutral surfaces, bordered layouts, and rounded geometry with Aitia's own brand and content.
